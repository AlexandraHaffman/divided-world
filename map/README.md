# Карта — что где лежит и что можно править руками

## Коротко

| Файл | Можно править? | Что внутри |
|---|---|---|
| `data/factions.js` | **да** | Названия фракций, цвета, точка камеры |
| `data/locations.js` | **да** | Города, фронты, объекты: текст, координаты, фото |
| `data/factions-geo.js` | нет | Очертания территорий, собраны скриптом |
| `data/land.js` | нет | Береговая линия, собрана скриптом |
| `tools/` | — | Проверка координат и уплотнение границ, см. ниже |
| `index.html` | по необходимости | Сама карта |
| `editor.html` | — | Конструктор локаций (на сайте) |
| `editor-local.html` | — | Тот же конструктор, но одним файлом для работы с диска |

Правило простое: если файл начинается с шапки «**ЭТОТ ФАЙЛ МОЖНО И НУЖНО
ПРАВИТЬ РУКАМИ**» — он ваш. Если с «**СГЕНЕРИРОВАННЫЙ ФАЙЛ**» — его
перезапишет скрипт, и правки пропадут.

## Поправить текст фракции

Откройте `data/factions.js`, найдите нужный блок по названию и меняйте.
Сейчас в блоке только привязка территории — описания сняты и будут
написаны заново. Чтобы у Конфедерации Междуречья появился лидер и
описание, допишите две строки:

```js
{
  key:    "shumery",
  name:   "Конфедерация Междуречья",
  col:    "#1abc9c",
  clat: 34, clon: 43,
  leader: "Эна",
  ideo:   "Возрождение древнейшей цивилизации...",
}
```

`key` не трогайте — он связывает фракцию с её территорией и с локациями.
`col` тоже: те же цвета прописаны на главной странице и на страницах
фракций в папке `factions/`, они должны совпадать. Свободно меняются
`name`, `leader`, `ideo` и `clat`/`clon` — точка, куда прилетает камера
при клике в легенде. Пустых полей карта не боится: нет `leader` — строка
«Лидер» в карточке просто не покажется.

## Конструктор локаций

Проще всего не править `locations.js` руками, а собрать локацию в
конструкторе — он сам следит за форматом.

**На сайте:** `map/editor.html`, пускает по тому же коду, что и карта.

**Локально, без интернета:** скачайте один файл `map/editor-local.html`
и откройте двойным щелчком. Внутри уже лежат и суша, и фракции, и все
существующие локации — больше ничего скачивать не нужно.

Что он умеет:

- поля меняются под тип локации: у города одни, у фронта — интенсивность
  и стороны, у базы — вместимость и назначение;
- координаты ставятся кликом по карте, и она сразу пишет, попала ли точка
  на сушу и на чью территорию — метка в море сразу видна;
- фотографии перетаскиваются мышью, запоминаются их имена;
- черновик сам сохраняется в браузере, можно выгрузить и позже дозагрузить;
- кнопка «Взять локации с карты» подтягивает все существующие — удобно,
  когда нужно поправить уже стоящий город.

Готовое отдаёт в двух видах: **JSON** — прислать мне вместе с картинками,
или **готовый блок для `locations.js`** — вставить в файл самой.

Локальную версию я пересобираю после правок данных, чтобы в ней были
свежие фракции и локации: `node build-local-editor.js` из папки `map`.

## Добавить локацию

Откройте `data/locations.js`, скопируйте любой блок `{ ... }` целиком
и поменяйте поля. Обязательных всего пять:

```js
{
  name: "Новый город",
  type: "city",
  faction: "tenebrion",
  lat: 48.2,
  lon: 16.4,
}
```

- `type` — вид метки: `capital`, `regional_capital`, `city`, `base`,
  `settlement`, `landmark`, `anomaly`, `frontline`. От него зависят форма,
  размер и то, с какого приближения метка появляется.
- `faction` — ключ из `factions.js`, от него берётся цвет. Для ничейной
  локации напишите `""`.
- `lat` / `lon` — широта и долгота. Север и восток положительные.

Все остальные поля необязательны и показываются в карточке только если
заполнены. Полный список с пояснениями — в шапке самого файла.

## Не вся суша занята фракциями

фракциям принадлежит 131.6 млн — 89%. Остальные 16.1 млн ничьи, и для
локации в таком месте нужно писать `faction: ""` — метка будет серой.

## Проверить координату

В папке `tools/` лежат три скрипта. Python нужен любой третьей версии,
ничего доустанавливать не надо.

**Куда попала точка** — на сушу или в воду, и на чью территорию:

```
python3 map/tools/whereis.py "Вена,48.21,16.37" "Токио,35.68,139.69"
```

```
Вена       48.210, 16.370  суша -> tenebrion
Токио      35.680,139.690  суша -> (ничья)
```

Той же командой можно проверить весь файл локаций разом — она пройдёт по
`locations.js` и покажет всё, что стоит в море или не в своей фракции:

```
python3 map/tools/whereis.py --check-locations
```

**Готовые координаты** — `tools/cities.txt`: 168 настоящих городов с
пометкой, кому принадлежит место. Можно просто взять оттуда строку, а
можно прогнать файл целиком и убедиться, что после правки границ ничего
не разъехалось:

```
python3 map/tools/whereis.py --file map/tools/cities.txt
```

**Где ничья земля** — `tools/freeland.py` считает это прямо по данным
карты, так что список не устареет после правки границ:

```
python3 map/tools/freeland.py                 # куски крупнее 100 тыс. км²
python3 map/tools/freeland.py --min 5000      # и мелкие острова тоже
python3 map/tools/freeland.py --points 5      # по 5 точек внутри каждого
```

Одна оговорка про берег. Береговая линия собрана из Natural Earth и
огрублена, поэтому у самой кромки точка может оказаться «в море», хотя
город там есть: так вышло с Владивостоком, Магаданом, Карачи, Триполи,
Монтевидео и Давао. Лечится сдвигом на 5–15 км вглубь — в `cities.txt`
это уже сделано и помечено комментарием.

## Добавить фото локации

1. Положите файл в `data/images/locations/`
2. Впишите его имя в блок локации:

```js
photo: "loc-vienna.webp",
```

Картинка появится сверху карточки и подгружается только когда карточку
открыли — на скорость карты это не влияет. Если файла не окажется,
карточка просто покажется без него. Удобный размер — примерно 16:9,
ширины 800 px достаточно.

## После правок

Обновите страницу с очисткой кэша (Ctrl+F5 или Cmd+Shift+R). Если карта
не открылась совсем — почти наверняка в файле пропущена запятая или
кавычка: откройте консоль браузера (F12), там будет номер строки.

## Как пересобрать геометрию

Нужно только если меняется сама география — границы стран или состав
фракций. Скрипты лежат вне репозитория, попросите пересобрать.
Исходник — GeoJSON Natural Earth Admin-0.

Уплотнить уже собранные границы можно на месте — `tools/densify.py`
добавляет промежуточные точки в рубленые участки контура сплайном
Catmull-Rom, не сдвигая сами очертания:

```
python3 map/tools/densify.py --target 1.5 --dry   # показать, что будет
python3 map/tools/densify.py --target 1.5         # и записать
```

Внутри зашит список из 16 приграничных городов: если после уплотнения
хоть один выпадет из своей фракции, скрипт откажется писать файл. После
любой правки данных пересоберите локальный редактор:
`node build-local-editor.js` из папки `map`.

## Про скорость

Карта намеренно собрана «дёшево», и это стоит беречь:

- кадр рисуется только когда что-то меняется — неподвижная карта не
  нагружает видеокарту вообще;
- звёзды рисуются один раз, а не считаются шейдером каждый кадр;
- свечение везде сделано спрайтами и обводками, `shadowBlur` не
  используется нигде — это самый дорогой эффект в Canvas;
- вблизи подгружается детальное окно только видимого участка, и только
  когда карта остановилась.

Если добавлять эффекты — держитесь этих же правил, иначе на слабом
ноутбуке карта поедет.
