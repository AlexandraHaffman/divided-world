# Легендарные страницы персонажей

Каждая страница в этой папке (`dorn/dorn.html`, `wistner/wistner.html`, `emil/emil.html`, ...) —
самостоятельный дизайн под конкретного персонажа: свои CSS-переменные, свой шрифтовой микс,
своя мета-сила как визуальный лейтмотив. Не копировать секции одной страницы в другую 1:1 —
у каждого персонажа должна быть собственная структура блоков, отражающая его природу.

Несколько технических правил при этом сквозные для всех:

## Три рендера, не три файла

Каждая страница обязана адаптироваться под три диапазона через CSS media queries **в одном
HTML-файле** — никогда не через отдельные мобильную/десктопную версии:

- мобильный портрет — базовый рендер по умолчанию (≤600px)
- мобильный ландшафт / планшет (601–900px)
- десктоп (≥901px)

После любых правок вёрстки — особенно после добавления новых блоков с картинками —
проверять все три ширины, а не только ту, в которой правился код. Компонент, который красиво
лёг в одну колонку (например, узкая карточка биографии), может сломаться при переносе в
двухколоночную сетку на более широких брейкпоинтах — учитывать это заранее, а не патчить постфактум.

## Прочее

- Кнопка «✕ ВЫЙТИ» ведёт на `../../index.html` (список персонажей), не на корень сайта.
- Новую страницу нужно зарегистрировать в `characters/dossier.js` →
  `LEGENDARY_DOSSIER_SLUGS`, иначе карточка персонажа на общей странице не получит
  ссылку «▸ ЛЕГЕНДАРНОЕ ДОСЬЕ» (условие показа — `threat_level >= 50`).
- Никаких служебных цифр (threat/tier) в самой вёрстке — это метаданные карточки, не часть досье.
- Изображения — плейсхолдеры по путям вида `<slug>-<сцена>.<ext>`, автор раскладывает их сама
  позже. На странице должен быть мягкий fallback на случай отсутствующего файла (см.
  `.img-wrap`/`.broken` в `emil/emil.html`) — без брони, без alert.
- Если для промптов картинок пишется внешний референс (артефакт, доп. файл) — соотношение
  сторон должно быть внутри самого текста промпта, а не только в подписи рядом: без этого
  генератор берёт свой дефолт и результат может уехать в произвольный аспект.
